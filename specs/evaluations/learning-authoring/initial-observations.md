# Initial authoring observations

The six preserved JSON outputs use a neutral host contract: nodes carry label,
summary, explanation, example and source; edges carry source, target and label.
They are initial authored content, not independent model-session transcripts.
Baseline and guided content are identical. After reading the skill, the author
could not honestly reconstruct an unexposed baseline. Deliberately degrading
one condition would manufacture an effect. This comparison therefore cannot
estimate an improvement due to guidance.

Observed content limitations before UI runs: explanations mostly repeat the
summary, and generic study questions are not worked examples. The process
walkthrough omits main moving while a PR is open. Source paths identify files
but do not quote the supporting passages. The prerequisite brief mixes type
references with conceptual prerequisite relations; the explicit edge labels
avoid silently presenting imports as learning order, but the lesson needs a
clearer conceptual sequence. No human learner outcomes have been measured.

No canonical skill change is justified yet: existing guidance already calls
for fuller explanations and useful examples. These authoring failures show
incomplete execution of that guidance rather than a demonstrated missing rule.
Compilation, UI validation, scoring and local gates are pending.
