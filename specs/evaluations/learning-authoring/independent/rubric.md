# Frozen independent scoring rubric

Frozen 2026-11-18 before independent sessions. Evaluator-only, do not include
in author packets. Score initial and repaired outputs separately. Attribute
observations to exact output commits and distinguish static inspection from
executed behavior. No aggregate score is a human learning outcome.

Each dimension scores 0 absent or incorrect, 1 partial, 2 complete:

| Dimension | Complete criterion |
| --- | --- |
| Factual grounding | Claims supported by supplied sources, traceable citations, uncertainty marked |
| Edge semantics | Meaningful relationships, explicit source-to-target convention, correct endpoints |
| Rich summaries | Concise informative content readable at declared size |
| Details/examples | Fuller explanation, why it matters, useful examples marked when illustrative |
| Search | Relevant domain queries reach concepts and supporting details |
| Accessibility | Keyboard search/inspect/follow/close, focus return, readable narrow layout and non-hover reading path |

Record concrete evidence and missing checks for every dimension. Compile each
output in a consumer outside the workspace against published 0.2.0, strict
TypeScript and vite/client CSS types. Validate desktop and phone touch
emulation in headless Chromium with screenshots; check empty search, inspect,
follow, close, outline, overflow and reduced motion. Record errors and repairs.
Do not report screen-reader, real-device or human learner success unless
actually performed. Compare conditions per brief without inventing causal
certainty from a small unblinded agent-scored sample.
