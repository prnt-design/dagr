# Authoring brief: prerequisites

Create a prerequisite lesson that helps a React developer learn the concepts needed to author a Dagr Explorer. Use the supplied Explorer source material.

Deliver a self-contained React TypeScript component for published
@prnt/dagr-explorer 0.2.0 and any supporting data. Use public APIs and
only the supplied content sources for factual claims. Save the initial
output before compile or browser repairs, then preserve errors and repair
diffs. Do not read other author outputs or pilot reports.
